# WanderLux Travel Agency — ICT502 Assessment 2

This is an educational demonstration website with six responsive pages: Home, Destinations, Trip Calculator, Appointment, About Us and Contact. It has a rotating banner, scroll animations, JavaScript trip estimator, client-side form validation, and an OpenStreetMap embed.

## Run
Open `index.html` in a browser. All files are at repository root.

## Trip estimator
Rates are fictional AUD teaching examples, not travel offers or booking quotes.

## Contact and appointment forms
These forms validate inputs but **do not send, store, or submit user data**. Configuring a real email recipient and authenticated form processing is required before genuine submissions are possible. Do not claim otherwise in the assessment.

## Hosting
Render static site: build command `echo ready`, publish directory `.`. Add the actual working live URL to the assessment report.
